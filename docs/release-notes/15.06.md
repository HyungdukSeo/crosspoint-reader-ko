# 15.06 — Nape Pro BLE HID 연결과 페이지 넘김

Keychron Nape Pro 연결 성공 경로를 기준으로 BLE HID 메뉴와 연결 처리를 정리했습니다.
블루투스를 켜면 등록된 기기를 순서대로 다시 연결하고, 메뉴를 나가도 사용자가 끄기 전까지
블루투스 연결을 유지합니다.

## 주요 변경

- 블루투스 메뉴를 **ON/OFF**, **장치추가**, **등록된 키보드** 중심으로 정리했습니다.
- 등록된 장치는 저장되어 다시 ON 할 때 자동 연결을 시도합니다.
- 등록된 장치 목록에서 저장된 기기를 삭제할 수 있습니다.
- Nape Pro 연결에 성공한 direct9 방식의 보안 우선 연결 경로를 유지합니다.
- 리더 화면에서 BLE HID `PageUp` / `PageDown` 입력을 이전/다음 페이지로 처리합니다.
- 트랙볼 이동, 휠, 좌우 클릭 등 페이지 키가 아닌 입력은 리더에서 무시합니다.

## 빌드 검증

- `firmware.bin`: **6,149,120바이트**, OTA 한도까지 **404,480바이트** 여유.
- X3 이미지 헤더·체크섬·SHA 검증 통과.
- direct9 BLE 연결 기준 검증 통과.

## 사용 방법

1. **설정 → 시스템 → 블루투스 키보드**로 들어갑니다.
2. **ON**을 선택하면 저장된 장치를 먼저 연결합니다.
3. 새 장치는 **장치추가**에서 검색 후 연결합니다.
4. 책 화면에서 Nape Pro의 M1/M2에 매핑된 `PgUp` / `PgDn` 버튼으로 페이지를 넘깁니다.

SD 카드/OTA 업데이트에는 `firmware.bin`을 사용합니다.
