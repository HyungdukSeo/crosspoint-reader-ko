# 15.04 — 개인 OTA 채널 및 BLE 키보드 시험 기능

## 변경 사항

- OTA 업데이트 조회 대상을 `HyungdukSeo/crosspoint-reader-ko`로 변경했습니다.
- 버전을 `15.04`로 지정했습니다. 이후 이 저장소의 정식 Latest 릴리스에
  `15.05` 태그와 `firmware.bin`을 게시하면 기기의 업데이트 메뉴에서 인식합니다.
- 두 자리 버전, 기존 `1.5.0-ko.3` 형식, 잘못된 태그에 대한 버전 비교를 검증했습니다.
- BLE HID 키보드 검색·페어링·키 수신·메모리 측정을 위한 시험 기능을 포함합니다.

## 검증

- `firmware.bin`: **6,118,160바이트**. 기존 OTA 한도까지 **435,440바이트** 여유가 있습니다.
- X3 이미지 헤더·체크섬·SHA 검증 통과.
- 버전 비교 및 릴리스 JSON 처리 테스트 34개 통과.

## 설치 및 다음 OTA 업데이트

이전 펌웨어는 다른 저장소를 조회하므로, 최초 `15.04` 설치는 SD 카드 업데이트 등
기기에서 지원하는 방법을 사용해야 합니다. SD 카드/OTA 업데이트에는 **`firmware.bin`**을
사용합니다. `CrossPoint-15.04.bin`은 부트로더와 파티션을 포함한 전체 플래시 이미지입니다.

`15.04` 설치 후에는 업데이트 메뉴에서 Wi-Fi에 연결하고 새 버전을 확인할 수 있습니다.
업데이트는 사용자가 선택해야 설치됩니다. Draft와 Prerelease는 이 OTA 채널에 표시되지 않습니다.

## BLE 시험 범위

BLE는 부팅 시 꺼져 있습니다. USB 시리얼에서 다음 명령을 사용합니다.

```text
CMD:BLE:ON
CMD:BLE:SCAN
CMD:BLE:LIST
CMD:BLE:CONNECT:AA:BB:CC:DD:EE:FF
CMD:BLE:STATUS
CMD:BLE:OFF
```

키보드를 페어링 모드로 전환하고 SCAN 후 몇 초 기다린 다음 LIST를 실행합니다.
CONNECT 주소는 검색 결과의 실제 주소로 바꿉니다. 페어링 코드가 표시되면 키보드에서
해당 코드를 입력하고 Enter를 누릅니다. 수신된 키는 시리얼 로그로 출력합니다.

**화면에서 글을 입력하는 기능, 한글 조합, 메모 편집·저장은 아직 포함되지 않습니다.**
USB 시리얼이 차단된 기기는 이 시험 인터페이스를 사용할 수 없습니다.
실제 키보드 연결, 동작 중 메모리, 배터리 사용량은 아직 실기기에서 검증하지 않았습니다.

자세한 절차: [BLE 시험 문서](https://github.com/HyungdukSeo/crosspoint-reader-ko/blob/15.04/docs/ble-probe.md).
