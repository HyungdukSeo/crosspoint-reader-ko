# 15.05 — 기기에서 블루투스 키보드 검색·연결·입력 시험

15.04의 시리얼 전용 시험 기능에 **X3 버튼으로 사용하는 블루투스 메뉴**를 추가했습니다.
USB 시리얼 없이 기기 화면에서 시험할 수 있습니다.

## 빌드 검증

- `firmware.bin`: **6,127,696바이트**, 기존 OTA 한도까지 **425,904바이트** 여유.
- X3 이미지 헤더·체크섬·SHA 검증 통과.

## 사용 방법

1. **설정 → 시스템 → 블루투스 키보드 → 키보드 검색**을 선택합니다.
2. 키보드를 페어링 모드로 전환합니다. Clicks Power Keyboard는 Power 키를 누른
   상태에서 숫자 키 1~9를 눌러 추가 기기 페어링을 시작합니다.
3. 15초 후 목록에서 기기를 선택하고 확인 버튼을 누릅니다. 확인 버튼으로 검색을
   일찍 끝내고 결과를 볼 수도 있습니다.
4. 화면에 페어링 숫자가 나타나면 키보드에서 숫자를 입력하고 Enter를 누릅니다.
5. 연결 후 영문을 입력하면 시험 문자열과 마지막 키가 화면에 표시됩니다.
   확인 버튼은 문자열 지우기, 뒤로 버튼은 연결 해제입니다.

## 검색되지 않을 때

- 이름이나 HID 광고 정보가 없는 기기도 주소로 표시합니다.
- 검색 화면에 수신 신호 횟수를 표시합니다. 반복 수신도 포함됩니다.
- 메뉴의 **응답 요청 없이 검색**, **1M PHY로 검색**으로 비교할 수 있습니다.
- 목록에는 주변의 다른 BLE 기기도 나타날 수 있습니다. 연결 시 HID 지원을 확인합니다.

이 화면을 나가면 블루투스가 꺼집니다. 페어링 기록은 남아 **등록된 키보드**에서
다시 선택할 수 있습니다. 한글 조합, 메모 편집·저장, 다른 입력창에서 타이핑하는 기능은
아직 포함되지 않았습니다.

**Clicks Power Keyboard와 X3의 실제 검색·연결 성공은 아직 검증하지 않았습니다.**
이번 변경은 기기에서 직접 시험할 수 있는 화면과 검색 누락을 줄이는 처리를 제공합니다.

15.04 사용자는 업데이트 메뉴에서 Wi-Fi에 연결하면 이 릴리스를 받을 수 있습니다.
SD 카드/OTA 업데이트에는 `firmware.bin`을 사용합니다.
